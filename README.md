# Studiojd

preciso de uma page completa com integração ao gpt maker para agendar horário e saber mais sobre a profissional Jessica Dantas, especialista em alisamentos. Quero um site com o estilo contemporaneo moderno, com toques de plantas na cor rosa, e a predominancia do backgroud quero em preto, com tipografia elegante com alguns detalhes em dourado em botoes e contornos de bordas se caso tiver.  nesse site quero que tenha um mini formulario com nome, telefone, cidade e data de nascimento, para que seja captado leads na base de clientes da jessica. Quero tamabém uma estrutura fácil de ler, com hierarquia visual, com embasamento em UXUI em toda a jornada de usabilidade. A jessica é uma profissional caprichosa, correta,  e gosta de coisas práticas.
